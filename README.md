# 🛒 E-Commerce Sales Analytics Dashboard

A complete end-to-end Data Analytics project analyzing e-commerce sales performance using Python, NumPy, Pandas, Matplotlib, and Seaborn.

## Dashboard Preview

![Dashboard](images/dashboard_preview.png)

## Business Problem

The objective is to analyze sales transactions to identify customer behavior, product performance, regional profitability, and the impact of discounts on business profit.

## Tools & Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook
* Git & GitHub

## Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Feature Engineering
4. Exploratory Data Analysis
5. Business KPI Analysis
6. Customer & Regional Analysis
7. Profitability & Correlation Analysis
8. Business Insights

## Key KPIs

* Total Revenue
* Total Profit
* Total Orders
* Unique Customers
* Average Order Value
* Profit Margin (%)

## Key Insights

* Technology generated the highest sales revenue.
* Consumer customers contributed the largest share of revenue.
* Higher discounts generally reduced profitability.
* A small number of customers generated a significant portion of total sales.
* Some product categories had high sales but low profit margins.
